PRIVACY POLICY

隐私政策

哪些数据留在本机，哪些功能需要联网，我们在这里逐项说明。

更新与生效日期：2026 年 10 月 14 日 · 适用产品：雪行工具 iOS

简要说明：十项本地工具不要求注册；本地图片识别不上传图片。App 也包含可选联网服务，姓名查询会发送至服务端，因此整个 App 不属于“完全不收集数据”的产品。
维护与联系本地工具联网服务系统权限存储与删除你的选择

1. 维护与联系

本应用项目由 GitHub 维护者 yy7074 提供技术维护。关于隐私、支持或数据请求，请通过用户支持页面联系项目维护者。

当前公开联系渠道为官网仓库的 GitHub Issues。请仅提交不含敏感个人信息的联系请求；姓名、身份证件、电话号码、订单码和个人资料图片不应发布到公开讨论中。个人资料请求需先确认身份与合适的非公开沟通方式。

2. 本地工具处理的信息

  • 清单、计时与行程：保存清单条目和勾选状态、计时状态、你输入的行程名称与时间。
  • AA、日志、装备与坡度：保存金额与人数草稿、手动输入的滑行记录、装备档案与保养日期、部分坡度计算输入。滑行日志不自动获取定位，也不采集后台轨迹。
  • 图片识字：你通过系统照片选择器主动选择图片，应用使用系统 Vision 在设备上识别。识别图片不上传至本应用服务器，不另行保存原图；识别文字及识别时间保存在本机。你可以编辑、清除、复制或主动分享结果。
  • 全景预览：你选择的全景图片仅用于本次设备内预览，不上传至本应用服务器，不另行持久化。

本地记录保存在应用沙盒内的本机存储中，可能随你开启的设备备份机制纳入 Apple 系统备份。尚未下载的 iCloud 原图需先通过系统服务下载；这类下载和系统备份由 Apple 的服务与设置管理，并非本应用的图片上传接口。

3. 联网服务与请求信息

应用会请求远程服务可用配置。你选择进入联网冰雪服务并提交姓名时，姓名会作为 HTTPS 请求的查询参数发送到业务服务，用于匹配已配置的个人资料。服务可返回个人配置标识、页面图片、会员展示信息、订单、出行人和优惠券等内容；配置图片可能由相应图片主机加载。

服务主机在接收请求时可看到 IP 地址、访问时间、请求路径和查询参数等网络信息。代理、业务服务器和图片服务可能按各自配置保留请求日志。姓名查询和业务数据涉及的后台处理，与本地十项工具应分别理解。

这些信息用于请求对应服务、匹配配置和展示服务内容。项目维护者并未把其他应用/政务风格页面的演示呈现作为真实政务身份认证服务；相机流程演示不产生真实身份核验结果。

请仅使用你有权访问的姓名配置和服务资料。服务器提供的会员、订单、券码或图片可能包含个人信息，请勿向不相关人员公开或分享。

4. 权限与主动操作

  • 相机：仅在进入相关相机预览功能时请求。当前客户端预览流程不录制、不建立人脸模板，也不把相机画面上传至本应用服务器。
  • 照片：OCR 和全景通过系统选择器读取你主动选择的图片，不扫描整个相册。
  • 本地网络：当应用连接同一局域网服务时，系统可能按网络配置请求相关权限。
  • 剪贴板与分享：只有你点击复制或分享时，应用才把相应结果交给系统剪贴板或你选择的接收服务；接收方随后按其自身规则处理。

你可以在系统设置中管理相机及相关权限。拒绝相机权限不影响清单、计算等不使用相机的本地工具。计时、行程和保养功能当前不发送后台通知。

5. 服务提供方与跟踪

当前客户端使用 Apple 系统的 Vision、照片选择器、相机预览及分享能力；联网服务还涉及业务主机及其配置的图片主机。官网托管在 GitHub Pages，访问官网时 GitHub 会按其服务机制处理必要的请求信息，详见 GitHub 隐私声明。反馈 Issues 中主动提交的内容会由 GitHub 保存，公开内容对其他访问者可见。

当前客户端未集成广告 SDK，未调用跨应用广告跟踪能力，隐私清单声明不进行跟踪。我们不将本地工具记录通过客户端广告接口出售或用于跨应用广告画像。业务服务器的具体日志与数据处理仍应以其实际部署和服务说明为准。

6. 存储、保留与删除

本机数据在相应功能内持续保存，直到你编辑、删除或清除；全景导入图不另行持久化。可在清单中删除条目、在日志和装备档案中删除记录、在 OCR 中清除识别文字、在行程中清除计划。系统中的“卸载 App”与“删除 App”含义不同；删除 App 会移除其设备内应用数据，已有系统备份另按 Apple 设置管理。

切换个人配置会替换当前客户端中的个人展示信息。退出页面或删除 App 并不等于删除服务器已配置的资料、订单、优惠券或服务器日志。涉及服务端资料的访问、更正或删除，请先通过支持渠道联系维护者，在确认身份和实际服务处理方后提出请求。具体保留期限和完成时间取决于相应服务与必须保留的记录；本政策不把未核实的后端保留期限写成固定承诺。

我们建议只输入使用功能所需的信息，避免在自由文本、识别文字或公开反馈中存放敏感资料。数据传输使用客户端配置的网络连接方式；你选择的外部分享目标由其自身提供保护。

7. 你的选择与数据请求

你可以不进入联网服务，继续使用不依赖网络的本地工具；可以停止提交姓名、撤销相关系统权限、删除本机记录或停止使用应用。你可就与你相关的服务端信息申请了解、访问、更正或删除；请先提交不包含敏感内容的联系请求，维护者将确认适用的数据来源、身份验证方式和后续沟通渠道。公开 Issue 不适合传送个人资料或身份证件。

8. 未成年人

本应用不专门面向儿童设计。未成年人应在监护人指导下使用；涉及姓名配置、个人服务资料或外部分享时，应先征得监护人同意。监护人发现相关个人信息处理问题，可通过用户支持渠道联系维护者。

9. 政策更新

当产品功能或数据处理方式发生变化时，本页面将更新日期及内容；影响个人信息处理的重要变化应另按适用要求告知。最终发布版本和其实际服务数据流应与本政策保持一致。
